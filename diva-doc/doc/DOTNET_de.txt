***          Anweisungen zur .NET 8.0-Installation        ***
***                 für OpenSim                         ***
*** NUR Linux/Unix. Windows-Benutzer haben .NET 8.0 bereits. ***

Es gibt nicht eine einzige Reihe von Anweisungen zur Installation von .NET 8.0 auf Ihrem
Linux/Unix-Rechner -- die Installation hängt von Ihrer Linux/Unix-Variante ab. 
Mit Glück finden Sie den .NET 8.0-Installer für die exakte
Version Ihres Betriebssystems hier:
https://dotnet.microsoft.com/download/dotnet/8.0

Die .NET-Community stellt zusätzliche Installer über die von
Microsoft verfügbaren hinaus bereit. Verwenden Sie Google oder Ihre bevorzugte Website für
Informationen darüber, wie Sie .NET 8.0 auf Ihrem Betriebssystem installieren.

Wichtige Dinge, die Sie beachten sollten:

* OpenSim erfordert .NET 8.0 oder höher. Ältere Versionen von .NET werden
  OpenSim nicht ausführen. Aufgrund dieser Anforderung müssen Sie je nach Ihrem
  Betriebssystem möglicherweise .NET 8.0 aus den offiziellen Quellen installieren.

* Einige der neuesten Versionen von .NET funktionieren möglicherweise noch nicht gut
  mit OpenSim. Bitte recherchieren Sie und fragen Sie herum, um etwas über die
  Erfahrungen anderer Leute mit .NET 8.0 und OpenSim herauszufinden.

* Das .NET 8.0-Framework besteht aus der .NET-Runtime selbst zusammen mit
  mehreren anderen Komponenten wie SDK, ASP.NET Core usw. Wenn Sie
  nicht planen, weitere Anwendungen mit .NET zu entwickeln, ist das einzige, was
  Sie zum Ausführen von OpenSim benötigen, die .NET 8.0-Runtime selbst.

Sobald Sie .NET 8.0 installiert haben, geben Sie dies ein:
$ dotnet --version

Stellen Sie sicher, dass Sie die richtige Version installiert haben.
