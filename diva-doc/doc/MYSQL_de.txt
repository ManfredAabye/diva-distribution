*** Anweisungen für Installation und Konfiguration von MySQL ***
***      für die Diva-Distribution von OpenSim                ***

1 - Installieren Sie MySQL und optional MySQLAdmin. Siehe
    http://dev.mysql.com/downloads/
    Wenn Sie unter Linux sind, ist MySQL wahrscheinlich bereits installiert:
    $ mysql --version

Die Installation und Konfiguration von MySQL kann extrem einfach oder extrem
schwierig sein, abhängig von Ihrem Betriebssystem und Ihren Vorkenntnissen
in der Systemadministration. Die Installation von MySQL in modernen Windows-Versionen
ist unkompliziert, und Sie sollten keine größeren
Probleme antreffen. Ebenso haben die meisten modernen Linux-Systeme MySQL bereits
installiert; Sie müssen nur googeln, wie Sie es konfigurieren und den
Server als Daemon in Ihrer speziellen Linux-Version laufen lassen. Die Schwierigkeiten
nehmen bei älteren Betriebssystemen zu, die möglicherweise nicht die richtige
Version von MySQL (5 oder höher wird empfohlen) ausführen können. Wenn Sie
Schwierigkeiten beim Ausführen von MySQL haben, stellen Sie sicher, dass Sie viel googeln oder einen
Systemadministrator um Hilfe bitten.
     
Starten Sie nach der Installation den MySQL-Server und starten Sie die Befehlszeilen-
Konsole für das mysql-Root-Konto.

  $ mysql -u root -p -h localhost

Wenn das nicht funktioniert, versuchen Sie su oder sudo als Root
  $ sudo mysql

Als nächstes,
   - erstellen Sie ein Schema namens opensim:
         mysql> create database opensim;

   - erstellen Sie ein Benutzerkonto namens opensim mit einem beliebigen Passwort.
     Bitte wählen Sie ein gutes Passwort!
         mysql> create user opensim identified by 'ihr_passwort_hier';
     (Sie möchten vielleicht auch 
         mysql> create user 'opensim'@'localhost' identified by  
            'ihr_passwort_hier';
     )

   - geben Sie diesem Benutzer alle Privilegien für den Zugriff auf das 
     opensim-Schema:
         mysql> grant all on opensim.* to opensim;
         mysql> grant all on opensim.* to 'opensim'@'localhost';

   - lassen Sie den MySQL-Server die Benutzerdaten neu laden:
         mysql> FLUSH PRIVILEGES;


   HINWEIS: Die 2 mittleren Befehle sind nur für MySQL 5 verfügbar. Wenn Ihre
   Installation älter ist oder sie nicht funktionieren, tun Sie stattdessen dies:
     mysql> use mysql;
     mysql> insert into user (Host, User, Password, Select_priv,
       Insert_priv,Update_priv,Delete_priv,Create_priv,Drop_priv,
       Reload_priv,Process_priv,File_priv,References_priv,Index_priv,
       Alter_priv) VALUES ('localhost','opensim',
       PASSWORD('ihr_passwort_hier'),
       'Y','Y','Y','Y','Y','Y','Y','Y','Y','Y','Y','Y');
     mysql> FLUSH PRIVILEGES;

*** FEHLERBEHEBUNG ***
***********************

Wenn Sie OpenSim später ausführen, können Sie MySQL-bezogene Fehler wie diesen antreffen:

23:10:13 - ====================================================================
23:10:13 - STARTING OPENSIM 
23:10:13 - ====================================================================
23:10:13 - [OPENSIM MAIN]: Running in sandbox mode
23:10:13 - [DATASTORE]: Attempting to load OpenSim.Data.MySQL.dll
23:10:13 - [REGION DB]: MySql - connecting: Data Source=localhost;Database=opensim;User ID=opensim;Password=***;
23:10:13 - [APPLICATION]:
APPLICATION EXCEPTION DETECTED: System.UnhandledExceptionEventArgs

Exception: MySql.Data.MySqlClient.MySqlException: Access denied for user 'opensim'@'localhost' (using password: YES)
  at MySql.Data.MySqlClient.MySqlStream.OpenPacket () [0x00000]
  at MySql.Data.MySqlClient.NativeDriver.Authenticate411 () [0x00000]
  at MySql.Data.MySqlClient.NativeDriver.Authenticate () [0x00000]
  at MySql.Data.MySqlClient.NativeDriver.Open () [0x00000]
  at MySql.Data.MySqlClient.Driver.Create (MySql.Data.MySqlClient.MySqlConnectionStringBuilder settings) [0x00000]
  at MySql.Data.MySqlClient.MySqlPool.CreateNewPooledConnection () [0x00000]
  at MySql.Data.MySqlClient.MySqlPool.GetPooledConnection () [0x00000]
  at MySql.Data.MySqlClient.MySqlPool.TryToGetDriver () [0x00000]

Fehler wie dieser bedeuten, dass etwas mit Ihrer MySQL-Einrichtung nicht stimmt. Bei diesem speziellen Fehler wurde dem opensim-Konto @ localhost kein Zugriff auf den MySQL-Server gewährt. Das ist einfach zu testen:

$ mysql -u opensim -p -h localhost

Wenn Sie sich nicht so am Server anmelden können, dann kann OpenSim es auch nicht. Melden Sie sich wieder als Root an und stellen Sie sicher, dass das opensim-Konto @ localhost aktiv ist:

mysql> use mysql;
mysql> select Host, User from user;

Erstellen Sie zusätzliche opensim-Konten @ verschiedene Variationen des Hostnamens.
