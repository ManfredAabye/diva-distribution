Diese Distribution enthält eine vereinfachte und vorkonfigurierte 
Version von OpenSim für eigenständige virtuelle Welten im Hypergrid. 
Sie enthält:

1) eine Teilmenge der kanonischen OpenSim-Distribution. Für die vollständige
   Distribution siehe bitte
   http://opensimulator.org/wiki/Download

2) nur Binärdateien

3) zusätzliche Module und Tools, die externe Dienste verwenden
   (wie Suche) und die Konfiguration und Updates
   so einfach wie möglich machen. 

4) mehrere zusätzliche Addons, wie eine Webanwendung für Benutzer-
   registrierungen

5) Vorkonfiguration für die Verwendung von MySQL-DB-Backend, ODE-
   Physik und einer Standardwelt bestehend aus mehreren Regionen

6) zusätzliche Inhalte in der Bibliothek

Bitte lesen Sie LICENSE.txt bevor Sie diese Distribution von OpenSim verwenden.


******************************************
*** Zur Installation siehe INSTALL.txt ***
******************************************


 Um OpenSim auszuführen benötigen Sie: 
  - einen Computer mit Linux oder Windows und ausreichend
    Arbeitsspeicher (>1G). 

 Um auf andere Welten im Hypergrid zuzugreifen benötigen Sie:
  - eine extern sichtbare IP-Adresse oder einen Domainnamen (bevorzugt). 
    Wenn Sie nicht wissen, wie Sie eine extern 
    sichtbare IP-Adresse einrichten, könnte Ihnen das helfen:
    http://portforward.com/
    Sie müssen Portweiterleitung auf Ihrem Router einrichten, sodass aller
    Verkehr zu den Ports 9000 bis 9010, TCP und UDP, an den
    Rechner weitergeleitet wird, auf dem Ihr OpenSim läuft.

Dies ist eine unabhängige Distribution, die auf spezielle
Weise konfiguriert ist. Upgrades zu dieser Distribution sollten mit dem
mitgelieferten Upgrade-Tool durchgeführt werden. Manuelle Upgrades von der 
kanonischen OpenSim-Distribution oder anderen werden wahrscheinlich Probleme verursachen.
