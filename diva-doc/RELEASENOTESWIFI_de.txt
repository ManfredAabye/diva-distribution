diva-wifi-0-7-2

*** Änderungen seit der vorherigen Version:

- Fehlende Lokalisierungs-DLLs hinzugefügt (betrifft niemanden mit englischer
  Sprache)

- Unterstützung für SQLite

- (Dies ist keine neue Änderung und betrifft niemanden, der die
  Diva-Distro sofort verwendet, kann aber diejenigen betreffen, die sie weiter
  anpassen): Wenn Sie eine ältere Konfiguration für Wifi wiederverwenden,
  nutzen Sie möglicherweise nicht das volle Potenzial. Die neuesten Wifi-Versionen
  verwenden Diva.Data.MySql.dll als Speicher-Plugin, nicht
  OpenSim.Data.MySql.dll. Eines der Symptome dafür, dass Sie die
  "falsche" DLL verwenden, ist, dass die Startseite von Wifi 0 für alle
  Statistiken anzeigt. In diesem Fall wechseln Sie unter
  [DatabaseService] zur Diva-Version

*** Konfigurationsänderungen:

HINWEIS: Diese Änderung betrifft hauptsächlich Benutzer, die Wifi auf einem
Grid betreiben. Benutzer von Diva-Distro-Installationen werden dies automatisch
über DivaPreferences.ini aktualisiert bekommen und sollten sich keine Sorgen machen.

Die Art, wie Standard-Avatar-Typen angegeben werden, hat sich geändert. Früher gab es
genau 3 Typen, angegeben als
  FemaleAvatarAccount = "Female Avatar"
  MaleAvatarAccount = "Male Avatar"
  NeutralAvatarAccount = "Neutral Avatar"

Die Syntax hat sich jetzt geändert zu
  AvatarAccount_Neutral = "Neutral Avatar"
  AvatarAccount_Female = "Female Avatar"
  AvatarAccount_Male = "Male Avatar"

Stellen Sie sicher, dass Sie Ihre Konfiguration aktualisieren.

Diese neue Syntax ermöglicht die Existenz einer beliebigen Anzahl von Avatar-
Typen, wie folgt:
  AvatarAccount_<AvatarTyp> = "<Vorname> <Nachname>"
